# 🌟 CS2 作弊工具
这是Valorant轻量化作弊工具的CS2版本

同样支持自动架点，但不支持自瞄（CS2敌人没有高亮色）

但是加入了压枪宏，能在对战中获取较好的压枪体验，同时不那么明显，不大会被封号

# 配置文件修改
1. 在程序同级目录下需要有`configs.json`，建议直接拷贝仓库中的示例
2. 下面详细解释下各参数的含义
对于`serial`部分参数
> port：在Windows设备管理器中查看分配的COM编号，示例：`port = "COM7"`
> 
> baud：默认值：`9600`（与树莓派`main.py`中保持同步）

对于 `auto_trigger`部分参数
> hotkey：触发自动架点的热键，使用大狙对准过点，按下后保持鼠标不要移动，即可双手脱离，喝茶等击杀~
> 
> delay：默认1ms，用于演戏时加点迟钝，毕竟除去delay的70ms~100ms的反应不像人类所为
> 
> region_size: 这个一般不要改动，只准心附近真正感受到变化(有人过点)的区域大小
> 
> threshold: 这个在valorant中为50，在cs2中为15，可以描述为对过点像素变化的敏感度
> 

对于 `auto_controller`部分参数
> hotkey：按下后压枪射击（不需要按住左键），松手后停止射击
> 
> delay: 缓解串口通信带来的延迟，涉及代码层面，非常不建议改动！
> 
> switch: 切换m4a1与ak47两种压枪模式（起始是m4a1）
> 
> sens: 这里需要你更改为你自己的鼠标灵敏度
>
