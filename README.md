## 🎮 如何使用
### 一、树莓派Pico端

#### 1️⃣ CircuitPython环境部署

##### 1.1 固件烧录
1. **获取固件文件**
   - 官方途径：[CircuitPython官网](https://circuitpython.org/board/raspberry_pi_pico/)下载最新`.uf2`文件
   - 快捷方式：直接使用本仓库`/pico`目录中的预编译固件（已测试稳定版本）

2. **进入烧录模式**
   - 使用Micro USB数据线连接电脑
   - 按住Pico板上的`BOOTSEL`按钮（白色按钮）同时插入USB
   - 电脑将识别为`RPI-RP2`可移动磁盘

3. **完成烧录**
   - 将`.uf2`文件拖入`RPI-RP2`磁盘
   - 设备会自动重启，变为`CIRCUITPY`驱动器即表示成功

#### 2️⃣ HID库部署与程序加载

##### 2.1 安装库文件以及主运行文件
1. **获取文件**
   - 从本仓库`/pico`目录中复制`/lib`目录以及`main.py`文件
   - 粘贴到树莓派根目录中
2. **下载Thonny软件进行测试**
   - 下载地址：https://thonny.org/
   - 安装后选择解释器为CircuitPython
   - 打开`main.py`文件点击运行测试功能

### 二、计算机端

#### 1️⃣ 程序获取以及树莓派连接要求
1. 程序获取
下载`cheat.py`自行配置运行环境或直接下载`release`文件夹中的预编译`cheat.exe`文件
2. 连接要求
除标准USB数据线外，需额外通过USB转TTL模块连接树莓派Pico的GP3与GP4引脚到计算机
  GP3 → 计算机RX (接收端)
  GP4 → 计算机TX (发送端)

#### 2️⃣ 配置文件修改
1. 在程序同级目录下需要有`configs.json`，建议直接拷贝仓库中的示例
2. 下面详细解释下各参数的含义
对于`serial`部分参数
> port：在Windows设备管理器中查看分配的COM编号，示例：`port = "COM7"`
> 
> baud：默认值：`9600`（与树莓派`main.py`中保持同步）

对于 `auto_trigger`部分参数
> hotkey：触发自动架点的热键，使用大狙对准过点，按下后保持鼠标不要移动，即可双手脱离，喝茶等击杀~
> 
> delay：默认1ms，用于演戏时加点迟钝，毕竟除去delay的70ms~100ms的反应不像人类所为
> 
> region_size: 这个一般不要改动，只准心附近真正感受到变化(有人过点)的区域大小
> 
> threshold: 这个在valorant中为50，在cs2中为15，可以描述为对过点像素变化的敏感度
> 

对于 `auto_aim`部分参数
> hotkey：按下后自瞄+击杀一气呵成，如果打不准就多按几次，绝对比大部分人水平高得多！
> 
> size: 准心周围能触发自瞄的区域，非常不建议改大！
> 
> lower_color,upper_color: 涉及到我的自瞄原理了，valorant游戏敌人具有高亮色，我只要找出这个高亮色的范围即知道了敌人的位置，目前默认的敌人颜色就是黄色，偶尔会触发识别错误，在亮黄色更少的地图中使用更佳。有能力的人可以修改这部分色域实现更高的精度或者改换敌人颜色
> 
> sens: 这里需要你更改为你自己的鼠标灵敏度，并且可能需要在此基础上稍微调整，如果一次定位不到头上需要把这个值调小（没反！）如果一次定位过头则需要调大
> 
> offsets: 定位几乎精确的情况下该参数可以使得准心更接近头部中心，因为我代码中的定位点是头部左上点，所以需要一个小的偏移，一般来说该参数不需要改变
>
